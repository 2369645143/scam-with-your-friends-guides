## 哪些内容保存在什么地方？
10 月 23 日 **0.1.84** 增加三个存档，可在设置中按日期、转生预览选择，Steam Cloud 同步所有存档。10 月 25 日 **0.1.90** 将保存媒体与云进度分开处理。

| 内容 | 官方说明的保存行为 |
| --- | --- |
| 进度、外观、转生、检查点、永久应用购买 | 0.1.83 增加 Steam Cloud 支持。 |
| 三个存档文件 | 0.1.84 说明全部云同步。 |
| 画质、麦克风、语言、操作、音量设置 | 留在当前电脑。 |
| 新保存的录像、照片等媒体 | 0.1.90 使用本机存储，不通过 Steam Cloud 同步。 |
| 累计成就、统计、游戏时间 | 按 0.1.84 说明，重置、换档及转生后保留。 |

## 换档或换电脑前
1. 记下选中的槽位及日期、转生预览；误选另一个槽位可能看起来像丢档。
2. 结束当前游玩，检查 Steam 云同步状态后再去另一台电脑启动。若提示冲突，先比较时间与进度，不要盲目覆盖任一副本。
3. 在另一台电脑重新核对本机麦克风、语言和画质设置。
4. 分开检查进度与录像；只有录像缺失，不足以证明云进度失败。

这些是预防性检查，不保证某次冲突可以恢复。本页不猜测存档目录，也不建议删除存档文件。

## 为什么找不到录像？
**Stored Media History** 可选保留 10、100、全部或 None，视频与图片分别设限，默认是 10。超过限制的旧受管理文件会被移除；None 停止新保存视频、照片和画作，但临时老板回顾媒体仍可能可用。

先检查历史数量设置、录制所在电脑，以及它究竟是保存媒体还是临时回顾。回顾播放失败可以使用其他播放形式，但不代表一定留下永久视频文件。回顾同时没有声音时，参见[语音与日志](/zh/guides/audio-microphone-setup/)。

## Reset Save 会删除什么？
0.1.83 加入的 **RESET SAVE** 会清除进度、外观和永久应用购买，保留本机设置。它有确认步骤，不能作为普通连接修复；不要为了排查大厅或麦克风而重置。

## 客机进度异常如何报告？
记录主客机版本、选中槽位、日期与转生预览，以及缺少的具体内容。0.1.84 改善了客机金钱及应用购买的跨局保留，但不能据此认定每个现有存档都正常。
