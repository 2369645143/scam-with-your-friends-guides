## Confirmed desktop features

Steam lists remote access to fictional victim computers, an in-game paint app, a screen recorder, and a camera. The developer website shows a call on a Kolkata desktop. This is enough to describe the broad toolset, but not to assign version numbers or detailed product names to each app.

## Finding the controls in your build

Check the actual game's control screen and the visible buttons for each in-game application. The cited sources do not supply a shortcut table. This guide therefore does not assign keys to hang-up, remote disconnect, screen blanking, or calling functions.

Operating-system shortcuts on your real computer may affect the host system rather than the game. Use bindings shown by the current game build.

## Suggested desktop workflow

Before trying to combine tools, identify which window is the in-game call and which is the remote computer. Keep the current objective visible where possible. These are usability suggestions rather than a demonstrated optimized route.
