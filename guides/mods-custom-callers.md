## Applicable version and review
Checked **2026-10-15** against the PC Steam listing ahead of its planned Early Access unlock. No released build was tested. September closed-beta reports below do not establish launch behavior.

## Confirmed by Steam
The [official listing](https://store.steampowered.com/app/4954910/Scam_With_Your_Friends/?l=english) advertises moddable content and custom personalities using JSON and voice-cloning WAV files. Its current feature list includes **Steam Workshop**.

The [October 14 fan guide](https://scamwithyourfriends.net/mods/) says Workshop is not listed. That statement conflicts with the current official listing and is not adopted here. Following the store's Workshop link during this review redirected to the general Workshop page, so a working game-specific catalogue or installation flow is not confirmed.

## Closed-beta reports — not independently confirmed
The fan guide attributes a Character Creator to a September 15 developer Discord changelog and community caller sharing to September 16. We could read the fan report, but did not independently retrieve those Discord messages. Treat the editor, sharing browser and caller-pool controls as beta reports, not verified release instructions.

## Preparing a custom caller — editorial checklist
- Write a short fictional character description and save your draft separately.
- Keep your own original audio available if you intend to supply a voice.
- Inspect the installed game's documented sample before creating a JSON file.
- Test one change at a time and keep the original files for comparison.

No JSON field schema, audio duration, sample rate, installation directory or import command has been verified here. This page does not provide invented example files.
